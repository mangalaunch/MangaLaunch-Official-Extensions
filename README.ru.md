# MangaLaunch Official Extensions

[English](README.md) · **Русский**

Официальный пакет источников, которые поддерживает проект MangaLaunch. Перечисленные сайты работают независимо от MangaLaunch.

ID пакета — `official.mangalaunch.core.sources`. В нём девять сайтов и десять источников, поскольку MangaDex доступен на английском и русском. У всех источников указан `isNsfw: false`. Shikimori, AniList и MyAnimeList предоставляют только метаданные.

## Источники

### Английский

- **MangaDex** — `en.mangadex`
- **Mangakakalot** — `en.mangakakalot`
- **MangaFox** — `en.mangafox`
- **Weeb Central** — `en.weebcentral`
- **AniList** — `en.anilist`
- **MyAnimeList** — `en.myanimelist`

### Русский

- **MangaDex** — `ru.mangadex`
- **MangaChan** — `ru.mangachan`
- **Desu** — `ru.desu`
- **Shikimori** — `ru.shikimori`

## Переход с неофициального пакета

У пакетов разные ID, а перенесённые источники сохраняют прежние ID источников, тайтлов и глав. Для перехода нужна версия MangaLaunch с поддержкой передачи источников.

1. Обновите неофициальный пакет до версии без перенесённых источников и оставьте его установленным. Если вы уже удалили неофициальный пакет, установите его обновлённую версию.
2. Импортируйте официальный пакет и проверьте издателя.
3. Подтвердите передачу источников, их настроек и сессий входа. MangaLaunch проверит подписанный манифест прежнего пакета перед сменой владельца. Библиотека, история и прогресс чтения сохранятся.

При отключении или удалении старого пакета его ID источников остаются зарезервированными. Для передачи нужен подписанный манифест обновлённого пакета.

## Разработка и публикация

Используйте Node.js 22 или новее. Команда `npm test` проверяет контракты источников, парсеры и упаковку с временными тестовыми ключами. В репозитории есть модули источников, иконки, SDK, шаблон и инструменты.

Руководство по созданию расширений · [English](docs/AUTHORING_EN.md) · [Русский](docs/AUTHORING_RU.md)

[Сценарий выпуска](.github/workflows/release.yml) использует защищённое окружение `official-core-source-release`. Настройте в нём переменную `MLSOURCE_PUBLISHER_KEY_ID` и секрет `MLSOURCE_SIGNING_KEY_BASE64`. Используйте отдельный ключ издателя для этого пакета, сохраняйте его для обновлений и публикуйте отпечаток открытого ключа для проверки издателя. Рекомендованный ID ключа — `mangalaunch-core-official-2026`.

Сценарий проверяет, что тег выпуска указывает на публикуемый коммит. Имя архива по умолчанию — `official.mangalaunch.core.sources.mlsource`. Для локальной упаковки и подписи используйте [`build-package.ps1`](build-package.ps1).
